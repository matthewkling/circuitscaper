# circuitscaper: Circuit-Theory Connectivity with 'Circuitscape', 'Omniscape' and Dipole Methods

Landscape connectivity modeling with circuit theory. Users work entirely
in R with familiar objects (SpatRaster, file paths) while 'Julia'
handles computation invisibly. Runs all four 'Circuitscape' modes
(pairwise, one-to-all, all-to-one, advanced) and 'Omniscape'
moving-window analysis through the 'Circuitscape.jl' and 'Omniscape.jl'
'Julia' packages; these methods are described in McRae (2006)
[doi:10.1111/j.0014-3820.2006.tb00500.x](https://doi.org/10.1111/j.0014-3820.2006.tb00500.x)
and Landau et al. (2021)
[doi:10.21105/joss.02829](https://doi.org/10.21105/joss.02829) . Also
provides experimental dipole methods, which map pairwise,
omnidirectional and cross-era connectivity from random source-sink pairs
superposed on a single factored circuit, at a cost that doesn't grow
with the number of pairs.
